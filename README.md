# PielDeCabra

Aplicación web desarrollada para una productora de cine, orientada a facilitar información de la misma y adquirir visionados de documentales. Este proyecto está siendo utilizado y mantenido para un negocio real, por lo que continúa evolucionando con nuevas funcionalidades y mejoras.

## Tecnologías utilizadas

### Backend

* Spring Boot

### Frontend

* Angular
* SCSS

### Base de datos

* PostgreSQL

### Control de versiones

* Git

## Funcionalidades

* Adquisición de visionados de documentales.
* Gestión de documentales.
* Panel de administración.
* Interfaz responsive.
* Integración con base de datos PostgreSQL.

## Estado del proyecto

🟢 **En desarrollo**

La aplicación se encuentra en uso y continúa evolucionando con nuevas funcionalidades, mejoras de rendimiento y corrección de incidencias.
